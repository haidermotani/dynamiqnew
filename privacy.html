What this site does

The DYNAMIQ website is an information page for football and cricket jerseys, tees, and custom team kits. It does not have user accounts, a checkout, or a database.

No tracking, analytics, or cookies

This site does not run analytics, advertising, or tracking scripts. It does not set cookies.

The site uses temporary browser session storage for one purpose: to remember that the opening sequence has already played during the current browser session. This value stays in the visitor's browser, is not sent to a server, and is cleared when the browser session ends.

Order details and messages

The custom kit form does not send information to a website server. When the form is submitted, the details entered are placed into a message on the visitor's device and WhatsApp opens so the visitor can send that message to DYNAMIQ.

Product orders and questions also go directly to DYNAMIQ through WhatsApp. WhatsApp is a third-party service with its own privacy terms. Read the WhatsApp privacy policy for details about how WhatsApp handles data.

What DYNAMIQ receives

DYNAMIQ receives the information a visitor chooses to send in a WhatsApp message. This can include a name, phone number, team name, city, order details, and any notes or files the visitor sends.

Deleting conversation data

To ask DYNAMIQ to delete order details or conversation data, contact DYNAMIQ on __WA_DISPLAY__ by call or WhatsApp. State which conversation should be deleted. DYNAMIQ will act on the request in the WhatsApp conversation.
